# The layouts of the QMI messages that the data daemon builds or parses, as the IDL tables of the stock
# libqmiservices.so give them (FP6.QREL.16.111.0). Only the TLVs the code touches are listed, and all of Start
# Network, because the engine can carry any of its TLVs as an extra. The service number of DFS is libqmi's, the tables
# name none in the form this file was made from.
#
# A dump of the IDL tables of a newer copy of the library is compared with these layouts and must not
# differ in any of them. `cargo test -p dataos-qmi -p dataos-datacore` reads the same file and fails when a
# message the code builds or accepts does not fit it. Type texts: u8 to u64 and enum8/enum16 are the widths on the wire (the tables keep no signedness and no enum
# members), str[<=N] is a top-level string of at most N bytes, and X[<=N]/P an array of at most N items with a
# P byte count in front of it. req/opt is whether the table marks the TLV as mandatory.
#
# The route lookup (0xfff2) is in no service object: the stock code sends it as a raw message, built TLV by TLV
# with the numbering and widths of Start Network. The line below fails when a library starts to define it.
